277 in-game commands with exact arguments, the rank each needs, and what has to be true first. Read from the upstream server source (origin/main), 2026-11-10. <required> [optional=default] a|b = pick one. Click a command to copy it.

Read first

Built 2026-11-10 from the rsps.app/host Commands tab and server/plugins/** registerCommand handlers on origin/main.

If a command misbehaves, check the source: git grep -n '"<cmd>"' origin/main -- server/plugins.

Run them via scripts/agents/mcp.

Parsing: the line is split on whitespace, with no quotes. The command word is lowercased; :: or / prefix.

  • Player names are the rest of the line, so names with spaces are typed with spaces.
  • Name matching:
  • Prefix-matched (exact or unique case-insensitive prefix): teleto, teletome, glow, give, setlevel.
  • Exact name only: kick, mute, ban.
  • Numbers are parsed with parseInt. Bad or missing numbers are often a silent no-op; otherwise you get a usage message.
  • Item, NPC and object commands take ids only; no names.

Ranks: Player 0 < Mod 1 < Admin 2 < Owner 3 < Dev 4, and higher ranks include lower ones. world.json commands:permissions can override them.

  • Unmarked commands below are Dev. O = Owner, A = Admin, P = anyone.
  • Devs are invulnerable until ::mortal.

Most boss/minigame commands need you inside the fight/run first. The "go there" command is listed first in each group.

Avoid / side effects:

  • Server-wide: update, gameupdate, flood.
  • Writes to data or account files:
  • npcperm, npcanim, npcanimscan write data JSON.
  • reprocorruptsave truncates a save.
  • changepassword is real.
  • copybank replaces your bank.
  • rollback logs the target out.
  • Persistent: displayname (28-day cooldown), aggro (persists).
  • noclip has no off switch.
  • Opens an interactive prompt/UI: skull, redskull, displayname, items, npcs, npcanim(scan).
